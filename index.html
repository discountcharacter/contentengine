ContentEngine

A private publishing tool.

ContentEngine uploads short videos to its owner's own YouTube channels through the YouTube Data API. It schedules each upload, sets the title, description and tags, adds the video to a playlist on the same channel, and reads the channel's view counts so the owner can see what worked.

It is used only by its owner, on the owner's computer, with the owner's own channels. It is not offered as a service to anyone else, and it does not run on any server.

Read the privacy policy and the terms of service.
